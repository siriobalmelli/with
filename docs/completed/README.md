# docs/completed — archived phase documents

These documents record completed design and migration phases. They are
history, not doctrine: where they conflict with the specification, the
decision log, or a ruling (notably `&mut T` spellings that predate
mut.md Rev 8 / specification §15.1, and pre-D22/D27 ownership shapes),
the current specification and `docs/decisions.md` govern. Serialization
signatures here were repaired to D27 ruling 1; other historical
spellings are left as the record of what the phase actually said.
